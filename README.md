# AI Shopping Assistant

## Overview
This project is an AI-powered shopping assistant that helps users discover products using conversational interaction.

## Features
- Product recommendations
- Conversational shopping assistant
- Multiple product categories
- Smart product matching
- Interactive chat UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download project
2. Open index.html in browser

## Categories Supported
- Laptops
- Phones
- Watches
- Shoes
- Cameras
- Tablets
- Speakers
- Bags
- TVs
- Headphones
