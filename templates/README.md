# AI Shopping Assistant

## Project Overview

AI Shopping Assistant is a chatbot-based web application that helps users find products using natural language queries.

Users can:
- Search phones or shoes
- Filter by budget
- View product recommendations
- View product cards with images

---

## Features

- Chatbot interface
- Budget filtering
- Brand filtering
- Product recommendations
- Responsive UI

---

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON

---

## How to Run

1. Install Flask

pip install flask

2. Run application

python app.py

3. Open browser

http://127.0.0.1:5000

## Example Queries

- phone under 20000
- nike shoes
